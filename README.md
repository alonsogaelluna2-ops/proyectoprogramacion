# Descripción Del Proyecto
Casos sin Resolver es un juego de investigación criminal desarrollado completamente en Python. El proyecto consiste en presentar al jugador tres casos diferentes que deberá resolver mediante la observación y análisis de distintas pistas.

Cada caso cuenta con una historia, tres sospechosos y varias pistas que el jugador puede investigar. A través de un menú, podrá seleccionar el caso que desea jugar, consultar información, revisar las pistas disponibles y finalmente elegir al sospechoso que considera responsable.

El programa evaluará la decisión del jugador y mostrará si logró resolver correctamente el caso. También contará con un sistema sencillo de intentos y puntuación, permitiendo que el jugador obtenga una mejor calificación mientras menos errores cometa.

El objetivo del proyecto es crear un programa interactivo que permita poner en práctica conocimientos básicos de Python, como variables, condicionales, ciclos, funciones, listas y entrada de datos, desarrollando al mismo tiempo un juego sencillo y entretenido que utilice la lógica para resolver problemas.
